# Contributing

Issues and focused pull requests are welcome. Describe the game/mod version, panel version, and observable behavior for bugs. Do not include copyrighted game files or personal saves.

1. Follow [Contributor setup](docs/contributing/SETUP.md).
2. Choose the guide for [cheat descriptors](docs/contributing/CHEAT_DESCRIPTORS.md) or [application and adapters](docs/contributing/APPLICATION_AND_ADAPTERS.md).
3. Keep changes small and add focused tests.
4. Follow the [contribution workflow](docs/contributing/WORKFLOW.md).

Contributions are provided under GPL-3.0-or-later.
